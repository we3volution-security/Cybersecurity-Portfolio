# Evidence

This directory contains supporting evidence for the practical work and qualifications documented in this portfolio.

Evidence is provided to demonstrate practical activity rather than simply claiming completion.

## Contents

### Screenshots

```text
screenshots/
```

Screenshots from hands-on labs, virtual machines, command-line work and other practical exercises.

### Certificates

```text
certificates/
```

Certificates and qualification evidence for completed training.

## Evidence Principles

Evidence should:

* Demonstrate genuine practical activity
* Support the relevant lab or qualification
* Avoid exposing passwords, flags, tokens or sensitive information
* Avoid publishing personal information
* Avoid publishing material that compromises active training environments

Where screenshots are used, unnecessary sensitive information should be redacted.

**Evidence to be uploaded as practical work is documented.**
