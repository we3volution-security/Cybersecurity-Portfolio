# Screenshots

This directory contains screenshots supporting practical lab documentation.

Screenshots should be organised by training platform and learning stage where practical.

Example:

```text
screenshots/
├── pre-security/
│   ├── operating-systems/
│   ├── networking/
│   ├── web/
│   ├── programming/
│   └── attacks-and-defences/
│
└── security-101/
```

Screenshots should demonstrate meaningful activity such as:

* Terminal commands
* Virtual machines
* System configuration
* Network investigation
* Web requests
* Security tools
* Successful practical outcomes

Avoid screenshots containing:

* Passwords
* Tokens
* Private keys
* Personal information
* Active-room flags
* Sensitive target information

**Evidence to be uploaded as practical work is documented.**
