# Windows Fundamentals

**Platform:** TryHackMe
**Path:** Cyber Security 101
**Module:** Windows Fundamentals — Parts 1, 2 & 3
**Status:** ✅ Completed
**Environment:** Windows virtual machines / AttackBox / remote access
**Lab Type:** Hands-on VM, administration and security labs

---

## Overview

The Windows Fundamentals module provided practical experience working with Windows systems and introduced progressively deeper system administration, investigation and security concepts.

Across three connected rooms, the learning progressed from understanding the Windows desktop and filesystem to investigating system configuration, users, processes, services, logs and the Windows Registry, before moving into built-in Windows security controls.

The rooms use deployable Windows lab machines, with the TryHackMe AttackBox available as the attacker environment where required. Windows Fundamentals 1 explicitly introduces this virtual environment and provides a Windows Server 2019 Standard lab machine.

---
