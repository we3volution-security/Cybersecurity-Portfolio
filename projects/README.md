# 🌐 Public Technology & Cybersecurity Education

**Status:** 🔵 Actively Developing

I am developing an independent public-facing digital literacy platform.

The project originally focused on Web3, blockchain and cryptocurrency education.

It has since been deliberately stripped back from the original commercial/referral concept and is evolving into a **jargon-free, hype-free civic and digital literacy resource**.

The project increasingly incorporates:

* Cybersecurity awareness
* Scam recognition
* Phishing awareness
* Social engineering
* DYOR / source verification
* Web3 safety
* Wallet security
* Safe interaction with Web3 applications
* Digital literacy

The purpose is to help members of the public understand technology and its risks rather than simply telling them what to do.

---

## Long-Term Vision

The longer-term goal is to develop an interactive, AI-assisted learning environment where people can safely experiment with Web3 and cybersecurity concepts in a sandbox.

Potential learning areas include:

* Understanding wallets
* Understanding transactions
* Interacting with simulated smart contracts
* Recognising scams
* Identifying phishing
* Understanding malicious behaviour
* Developing safer online habits

The emphasis is on:

**Clarity → Safety → Understanding → Practical Experience**

---

## Cybersecurity Learning Connection

This project also contributes to my own cybersecurity development.

Researching:

* Scams
* Phishing
* Social engineering
* Malicious behaviour
* Web3 security
* Safe online interaction

requires understanding how attacks work and why people and systems become vulnerable.

As my formal cybersecurity training progresses, I intend to incorporate appropriate security knowledge into the educational platform.

This creates a continuous learning loop:

```text
Learn
  ↓
Understand
  ↓
Practise
  ↓
Explain
  ↓
Identify gaps
  ↓
Learn further
```

# 🔧 Earlier Web3 Literacy Platform Beta

A separate historical project documents the original version of the platform.

That repository contains the first production beta architecture, including JavaScript/Velo code, database logic, referral systems, automated jobs and frontend/backend interaction.

The original project is preserved because it demonstrates my early programming, system-design, troubleshooting and problem-solving development.

It also provides an opportunity to document the security lessons I have since learned from reviewing my earlier architecture.

The current public-facing platform is intentionally separate from that historical beta system.
